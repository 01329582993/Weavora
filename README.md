# 🧵 Campus-Hub – AI-Powered Academic Ecosystem  
*A unified, intelligent learning platform that weaves together classroom management, AI tutoring, AI grading, communication, and productivity tools into one seamless experience.*



---

## 🚀 Overview

**Campus-Hub** is an AI-enhanced academic platform built to eliminate the fragmentation of modern learning systems. Students and teachers currently switch between Google Classroom, WhatsApp/Discord, and various AI tools, causing confusion and reducing academic productivity.

Campus-Hub unifies everything into one ecosystem—AI tutoring, AI auto-grading, lecture explanation, real-time chat, resource organization, focus mode, and emergency alerts—through a single clean interface.

---

## 🎯 Project Objectives

- Provide a **centralized platform** for all academic workflows  
- Offer **course-specific AI tools** for tutoring, grading, and summarizing  
- Reduce teacher workload through **AI-assisted grading**  
- Improve communication with **real-time chat** and **emergency alert system**  
- Enhance learning through **past-paper analysis** and **focus mode**

---

## 🔍 Key Problems We Address

- Fragmented digital learning tools  
- No course-specific AI tutor  
- Heavy manual grading load  
- No reliable emergency communication  
- Missing intelligent study tools  

---

## 💡 Features of Campus-Hub

### 🧠 AI-Driven Features
- AI auto-grading using teacher-provided marking schemes  
- Course-specific AI tutor using RAG  
- Lecture explanation tool  
- Past paper analyzer  
- Topic importance scoring  
- AI meeting/class summarizer  

### 🎓 Classroom Management
- Create and join classes  
- Upload materials (PDF, PPT, videos)  
- Assignments, submissions, and gradebook  
- Structured announcements  
- Calendar for deadlines  

### 💬 Communication & Productivity
- Real-time chat and discussion threads  
- Focus Mode (distraction blocker)  
- Emergency alert broadcast system  
- Bug reporting  
- Resource management  
- Analytics dashboard
